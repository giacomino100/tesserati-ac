# Excel di esempio

Mettere qui **una copia anonimizzata** di ciascun file usato oggi:

- `acr.xlsx`
- `giovani.xlsx`
- `adulti.xlsx`

## Regole
- **Stesse colonne, stesso ordine e stessi fogli** dei file reali.
- **Dati finti** (nomi, codici fiscali, indirizzi inventati): ci sono dati di minori, non usare dati veri nel repository.
- Mantenere i **difetti tipici** dei file reali: celle vuote, date scritte in modi diversi, maiuscole/minuscole miste, spazi in più, righe di intestazione o totali. Servono per scrivere le regole di validazione.
- 10–20 righe per file bastano; includere almeno una famiglia con 3+ componenti distribuiti su più file.
